# کدهای خودآموز جریان

الکترونیک را از «مدار یعنی چه» تا ترانزیستور، سنسور و میکروکنترلر یاد بگیر. بدون خرید قطعه شروع می‌کنی: هر فصل یک مدار زنده در مرورگر دارد که موتور آنالوگ واقعاً حلش می‌کند، پس ولتاژ و جریان را اندازه می‌گیری، نه اینکه فقط باور کنی.

این مخزن کدِ کامل و قابل‌اجرای هر فصل از **[جریان — خودآموز الکترونیک از صفر](https://yaadestan.com/courses/jaryan?utm_source=github&utm_medium=repo&utm_campaign=jaryan)** در [یادستان](https://yaadestan.com/?utm_source=github&utm_medium=repo&utm_campaign=jaryan) است. توضیح اینکه هر خط چرا آن‌جاست، در خودِ فصل روی سایت آمده؛ این‌جا فقط کد است تا راحت برداری، اجرا کنی و تغییرش بدهی.

## استفاده
